# 表格快照 · TableSnap

> 第九届传智杯全国大学生数智创新与AI应用大赛 · AI 创新应用挑战赛（Vibe Coding）
> 组别：C 组（高职高专）　对应选题方向：**#3 多模态创意与微工具工坊**

**拍一张表格的照片，变成能编辑、能导出的表格。**
**而且它会主动告诉你：哪几个格子我拿不准。**

## 项目状态

开发中，当前仅有项目骨架，业务功能尚未实现。实时进度见 `docs/tech-doc.md`。

## 它和现有工具的区别

| | 扫描类工具 | 本项目 |
|---|---|---|
| 做什么 | 识别 → 给你结果 | 识别 → **标出自己不确定的格子** → 你只改那几个 |
| 你要核对什么 | 全部 | **只核对标出来的** |
| 对准确率的说法 | "准确率 99%"（无法验证） | "我不知道的地方，我告诉你" |

> **AI 认不准没关系，我知道它哪里不确定。**

## 核心机制

```
上传图片
   |
视觉模型对同一张图独立采样 3 次
   |
逐格比对
   3 次一致    -> 绿：高置信，直接采用
   2 一致 1 异 -> 黄：请确认（显示"两次是 7，一次是 1"）
   3 次全不同  -> 红：必确认
   |
再叠加程序化结构校验（不依赖模型）
   · 各行列数不一致
   · 数字列里出现文字
   · 空值比例异常
   · 合计行与明细对不上
   |
人工只改标出来的格子 -> 导出 CSV
```

**关键点：不确定性由「程序计算」，不依赖模型自报置信度。**

## 技术栈

| 层 | 选型 |
|---|---|
| 框架 | Next.js 16 (App Router) + TypeScript |
| 样式 | Tailwind CSS v4 |
| 多模态 | 智谱 GLM 视觉模型（服务端代理，Key 不下发前端） |
| 导出 | CSV（自行生成，无额外依赖） |
| 部署 | Vercel |

本项目**不使用数据库**：图片识别后即在前端内存中编辑，数据不落服务器。

## 如何运行

```bash
npm install
cp .env.example .env.local    # 填入 ZHIPU_API_KEY
npm run dev
```

打开 <http://localhost:3000>

环境要求：Node.js 18.18+（当前验证于 v24.19.0）

## 目录结构

```
app/            路由与页面
components/     复用组件
lib/            工具（模型调用、结构校验、CSV 导出）
docs/
  ai-log/       AI 协作留痕记录
  tech-doc.md   技术文档正文（源文件）
eval/
  cases/        评测样本（图片 + 真值标注）
  results/      评测结果
```

## 已知限制（主动声明）

- 只支持**规整表格**，不支持合并单元格
- 不支持手写体
- 单图处理，不做 PDF 批量
- 数据不持久化，刷新即丢
